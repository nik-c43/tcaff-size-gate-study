# Полный пакет собственной разметки

798 финальных ответов, оригиналы и промежуточная версия сохранены. **Канонический файл:** [originals/labels-final-canonical.json](originals/labels-final-canonical.json). Остальные финальные копии идентичны; версии не суммируются.

[Схема](schema.json), [CSV](labels.csv), [manifest с SHA-256](manifest.json), [файл контрольных сумм](checksums.sha256), [инвентаризация исходников](source_inventory.json), [ID и связь с наблюдениями](task_metadata.json), [эпизоды](episodes.json), [цепочки индексов наблюдений](observation_chains.json.gz).

[Протокол, ограничения и команды чтения](../docs/annotation.md). Здесь нет исходных изображений, bags, полной авторской геометрии или масок. Чтение всех ответов и проверка целостности не требуют датасета. Просмотр соответствующих RGB требует внешних данных.
