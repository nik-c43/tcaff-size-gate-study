# Полный пакет ручной разметки

Ручная разметка связывает геометрическую диагностику TCAFF с проверкой физической идентичности наблюдаемых предметов. В этом каталоге сохранены все **798 финальных ответов**, а также оригиналы, промежуточная версия и исходный шаблон. Канонический вход итоговых метрик — [originals/labels-final-canonical.json](originals/labels-final-canonical.json); остальные финальные копии совпадают с ним и не считаются дополнительными наблюдениями.

Для чтения ответов доступны [CSV](labels.csv) и [схема полей](schema.json). [Метаданные заданий](task_metadata.json) связывают ответы с эпизодами, роботами и наблюдениями, [episodes.json](episodes.json) описывает отбор, а [цепочки индексов](observation_chains.json.gz) позволяют восстановить соответствующие кадры из внешних данных. Эти связи сохраняют контекст разметки без включения самого датасета.

Полнота переноса проверяется по [manifest](manifest.json), [контрольным суммам](checksums.sha256) и [инвентаризации исходников](source_inventory.json). [Протокол разметки](../docs/annotation.md) объясняет категории, уверенность, неоднозначные случаи и команды чтения. Просмотреть все ответы и проверить их целостность можно без датасета; для просмотра RGB нужны внешние bags. Исходные изображения, маски и полная авторская геометрия здесь не хранятся.
