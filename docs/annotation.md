## Схема и единица

Исходный JSON содержит `fingerprint`, `annotator`, `labels`. Каждая запись: `task_id`, `label`, `confidence`, `notes`. ID P0001–P0798 сохранены. [Машиночитаемая схема](../annotations/schema.json); шаблон и незавершённая версия допускают `null`, финальная — только заполненные категории.

| Значение label | Смысл ответа |
|---|---|
| `same_object` | Визуальные данные указывают на один физический объект |
| `different_objects` | Разные физические предметы |
| `part_whole_or_ambiguous` | Часть/целое, группа или неоднозначное разделение |
| `cannot_tell` | Установить идентичность по доступным наблюдениям нельзя |

Уверенность: `low`, `medium`, `high`; комментарий сохраняется дословно, включая пустую строку. В финале: 314/341/67/76 меток по порядку таблицы; уверенность high/medium/low = 616/101/81. Неопределённые ответы не превращаются в отрицательные или положительные.

Единица — записанный ответ на **пару объектов карты в выбранном якоре**. Дедупликация по паре track ID даёт те же 798 пар, но это не дедупликация по физической идентичности: один предмет может иметь несколько ID, а один трек участвует в разных парах. Геометрическая близость, ID трека и центр не являются доказательством идентичности. Допуск фильтра не означает принятую ассоциацию CLIPPER.

## Как отбирался пул и что видел разметчик

24 разнесённых якоря из одной записи, шесть канонических пар роботов, падение максимального взаимно однозначного XYZ-прокси ≥5→<5 после B0. Радиус 0.6 м; разнесение ≥40 обновлений внутри пары. Все близкие ребра на якоре включены без отбора по решению фильтра; допущенные ребра и близкие альтернативы служат контролями, но не получают автоматические метки.

Первичный интерфейс показывал реальные RGB-контексты, последнее/первое и некоторые промежуточные наблюдения трека, синхронизированные якорные изображения. Размеры, отказ фильтра, результат позы, split и роли контролей были скрыты. Код исходного интерфейса: [size_gate_review.html](../scripts/original/size_gate_review.html); генераторы [images](../scripts/original/size_gate_images.py) и [prepare](../scripts/original/size_gate_prepare.py). Сейчас это архив выполненной процедуры, а не обязательный путь чтения готовых ответов.

**Маски и точные границы детекций отсутствуют.** Нанесённые эллипсы — 2σ сохранённой ковариации в изображении, а не контуры сегментации. Context crop — область для просмотра, не авторский bounding box. Не дорисовываются предполагаемые маски.

## Происхождение ID и наблюдений

[task_metadata.json](../annotations/task_metadata.json) связывает каждый ответ с эпизодом, парой роботов, шагом/временем, map index, track ID, размерами карты, причиной отказа, временем последнего наблюдения и относительными путями внешних изображений. [episodes.json](../annotations/episodes.json) фиксирует отбор и split. В [observation_chains.json.gz](../annotations/observation_chains.json.gz) сохранены 696 уникальных цепочек `[frame_index, detection_index, time]`; `source_chain_id` — ключ дедупликации, **не новый физический ID**.

Индексы кадров/детекций — нулевые индексы исходных FastSAM JSON. Anchor RGB синхронизирован между роботами; последние наблюдения треков могут быть сделаны в разное время, смещения явно сохранены. Дата/ID независимой авторской записи не были предоставлены: `recording_id=null`, дана ссылка на единственный набор `tcaff_mot_data`. Физических ID, классов, масок и точных object bounding boxes не выдумывается. Исходные XYZ и ковариации всего авторского набора сюда не копируются.

## Оговорки, сохранённые после разметки

- В плотных группах коробок человек первоначально считал каждую коробку отдельным предметом; коробка/группа могла отмечаться `same_object/low` либо `part_whole_or_ambiguous/high`. Ответы не переписаны задним числом. Такая неоднородность учитывается как ограничение.
- Сходные признаки на роботах и на полу не гарантируют статический ориентир. Встречные наблюдения одинаковых роботов могут относиться к разным физическим роботам; случайная правильная поза не превращает их в один объект.
- Стол и лампа над ним могут иметь сходный XY-центр в данной сцене, оставаясь разными предметами. Геометрический успех не является критерием ручной идентичности.
- Один разметчик, один набор условий, отсутствие физических ID и масок. Высокая уверенность не равна независимому подтверждению. Не оценена межэкспертная согласованность.

## Чтение, экспорт и проверка

Без датасета, нейросетей и сторонних пакетов:

```bash
python3 scripts/inspect_saved.py
python3 scripts/read_annotations.py --task P0002
python3 scripts/read_annotations.py --html /tmp/tcaff-labels.html
```

Готовый [CSV](../annotations/labels.csv) сохраняет все ID, метки, уверенность и комментарии. Проверка сравнивает CSV с исходным JSON целиком. SHA-256 всех оригиналов сверяется, число ответов не меняется. HTML — небольшое средство чтения уже готовых ответов с поиском; не новый слепой эксперимент.

## Реальные иллюстрации

Выбраны четыре задания: P0002 — `same_object/high`, исключено B0; P0034 — `different_objects/high`, допущенный контроль; P0026 — часть/целое высокой уверенности; P0179 — `cannot_tell/low`. [Выбор и назначение](../annotations/examples.json). Они не репрезентативны. Ответ для P0002 сохранён как пользовательский; изображения роботоподобных сегментов не используются для независимого доказательства идентичности.

Право распространения авторских RGB не установлено. Поэтому картинки собираются только локально, **вне репозитория**. При наличии внешнего прежнего пула:

```bash
export MPLCONFIGDIR=/tmp/tcaff-study-mpl
.venv/bin/python scripts/render_real_examples.py \
  --pool "$STUDY_POOL" --output /tmp/tcaff-real-examples.png
```

`STUDY_POOL` указывает на внешнюю `annotation_blind/` с `images/`. `--blind` скрывает ответ, размеры и решение фильтра в подписи. Просмотр первых/последних кадров и якорной синхронизации доступен по метаданным; выбранная иллюстрация использует последние наблюдения, **не объявляет их синхронными**. Файл provenance рядом с PNG сохраняет ID и SHA изображений. Сборка проверена на имеющемся внешнем пуле.

Если готового пула нет, нужны исходные bags, JSON и приватный manifest. В подготовленном внешнем workspace исходная проверенная процедура — `.venv/bin/python scripts/size_gate_images.py` и `.venv/bin/python scripts/size_gate_finalize.py`. Она восстанавливает полный локальный пул; публиковать этот пул не требуется и не разрешается автоматически. [Ограничения точного воспроизведения](reproduction.md).
