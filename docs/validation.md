Скрипт [verify_repository.py](../scripts/verify_repository.py) проверяет индекс Git, относительные Markdown-ссылки/якоря, отсутствие авторского датасета и ROMAN-импортов, закрепление submodules, неизменность картирования/GT по SHA/AST, ограничения параметров прогонов и источники таблицы доказательств. Команда из корня после `git add .`:

```bash
python3 scripts/verify_repository.py
```

[Итоговый аудит индекса и ссылок](package_checks.json) и [контроль сохранения источника](source_preservation.json) фиксирует SHA проверенных исходных файлов: они не изменены. Upstream tracked-деревья остались чистыми; прежние untracked CMake-файлы CLIPPER сохранены. Корневой служебный `.git` старого проекта не переинициализировался. `git diff --check` для написанных скриптов и Markdown прошёл; побайтовые архивы, release YAML, demo и автоматически сгенерированный SVG сохраняют исходное форматирование. Whitespace-замечания к ним не исправлялись.

До подачи остаются действия вне выполненной локальной подготовки: выбрать лицензию собственного кода/разметки при необходимости, отдельно разрешить публикацию, создать GitHub-репозиторий и отправить ссылку. Авторские картинки исключены из-за неустановленного разрешения; это не ограничивает полноту опубликованного пакета ответов. Полный baseline, новая серия абляции и чистая установка после упаковки не выполнялись. Новая гипотеза не реализована и не проверена.
