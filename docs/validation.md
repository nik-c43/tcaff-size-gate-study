# Проверки подготовки и редакторской правки

Проверки разделены по своему назначению. При исходной подготовке 9 октября 2026 года проверялся перенос экспериментальных материалов из рабочего проекта. При последующей редакторской проверке репозиторий клонирован с GitHub, документы переписаны в связное изложение и повторно проверены сохранённые результаты. Новые исследовательские серии не запускались; полная установка окружения с нуля не проверена.

## Исходная подготовка

Следующие результаты относятся к сохранённым протоколам исходного рабочего окружения. Они описывают целостность материалов и границы воспроизведения, а не новый эксперимент редакторской проверки.

## Редакторская проверка опубликованной копии

Правка охватывает Markdown-документы и контрольную сумму отредактированного `annotations/README.md` в `annotations/checksums.sha256`. README теперь последовательно объясняет воспроизведение компонента, ручную проверку идентичностей, обнаруженный компромисс размерного допуска и уточнённую гипотезу. Отрицательный результат глобального ослабления остаётся в отчёте как обоснование следующего шага. Файлы меток, конфигурации, численные результаты и код алгоритмов не менялись.

Для повторной проверки сохранённых данных и навигации используются команды из корня:

```bash
python3 scripts/inspect_saved.py
python3 scripts/read_annotations.py --task P0002
python3 scripts/read_annotations.py --html /tmp/tcaff-labels-review.html
python3 scripts/verify_repository.py
git diff --check -- '*.md'
```

`inspect_saved.py` проверяет все 798 ответов и агрегирует метрики 420 прогонов. `verify_repository.py` дополнительно проверяет индекс, локальные Markdown-ссылки и якоря, отсутствие датасета и ROMAN-импортов, закрепление submodules, неизменность картирования/GT по SHA/AST, параметры прогонов и источники таблицы доказательств. Для этой команды нужны инициализированные submodules. Вычисленные ошибки проверяются по сохранённым файлам; новые позы по исходным наблюдениям здесь не оцениваются.

После редакторской правки эти проверки выполнены в клонированной копии: проверены 123 локальные ссылки, 5 оригинальных файлов разметки, 798 ответов и сохранённые данные 420 прогонов. Для HTML использован путь `/tmp/tcaff-labels-review.html`, как в приведённой команде. README, отчёт и вспомогательные документы согласованы с сохранёнными метриками. При проверке индекса используются уже отслеживаемые файлы; `git add` нужен только при добавлении новых файлов, а не для обычной правки существующих документов.

## Что остаётся непроверенным

Чистая установка всех зависимостей, новый полный baseline и повтор размерной серии из опубликованной копии не выполнены. Отдельная запись отсутствует, а гипотеза совместного учёта размера и центра ещё не реализована. Авторские изображения исключены из-за неустановленного разрешения их распространения; все ручные ответы при этом сохранены. Лицензия собственного исследовательского кода и разметки пока не выбрана. Эти ограничения относятся к следующему этапу и явно отделены от выполненной проверки документов и сохранённых результатов.
