# Адаптация авторского demo для готовых детекций

Этот каталог содержит явно выделенную адаптацию `demo/` из `mit-acl/tcaff`, коммит `ff4ceab04b03fecabc4de9c9cbe7dbba4ab50df9`. Она обеспечивает воспроизведение компонента совмещения по готовым JSON и сбор диагностических входов, не изменяя сам алгоритм TCAFF. Авторская MIT license сохранена в [LICENSE](LICENSE).

В трёх файлах отложены импорты нейросетей, добавлена проверка NaN перед преобразованием отсутствующей оценки, сохранение диагностических входов и исправление вспомогательного индекса второго робота. [Фактический diff](../../docs/demo.patch) показывает изменения, а [описание происхождения](../../docs/provenance.md) отделяет их влияние от исследовательских модификаций.

Обязательный путь использует `DetectionData`. При `CAPTURE_CANDIDATES=1` сохраняются предложения и оценки, а `CAPTURE_MAPS=1` дополнительно сохраняет карты. Такие захваты содержат авторскую геометрию и остаются во внешней рабочей области. [Инструкция воспроизведения](../../docs/reproduction.md) описывает запуск и различает время работы менеджера и накладные расходы логирования.
