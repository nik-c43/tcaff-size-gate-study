# Явная адаптация авторского demo

Происхождение: `mit-acl/tcaff`, коммит `ff4ceab04b03fecabc4de9c9cbe7dbba4ab50df9`, каталог `demo/`. Авторская MIT license сохранена в [LICENSE](LICENSE).

Алгоритм TCAFF не изменён. Три адаптированных файла обеспечивают импорт по готовым JSON, NaN guard, диагностический захват и исправление вспомогательного индекса второго робота. [Фактический diff](../../docs/demo.patch), [область влияния](../../docs/provenance.md).

`CAPTURE_CANDIDATES=1` сохраняет предложения/оценки; `CAPTURE_MAPS=1` дополнительно сохраняет карты для TCAFF-диагностики. Эти результаты содержат авторскую геометрию и должны оставаться во внешнем workspace. Обязательный путь использует `DetectionData`, не нейросетевой frontend. Команды запуска находятся в [reproduction](../../docs/reproduction.md).
