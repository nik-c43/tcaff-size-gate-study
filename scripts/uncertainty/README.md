# Проверка калибровки границы погрешности (отчёт, §7.2)

Скрипты проверяют, можно ли без формы и семантики откалибровать границу расхождения двух наблюдений одного объекта по признакам маски. Результат — [calibration_feasibility.json](../../results/uncertainty/calibration_feasibility.json).

| Шаг | Скрипт | Окружение | Что делает |
|---|---|---|---|
| 1 | `extract.py WORKSPACE OUT_DIR` | `.venv` | Прогоняет трекер карты TCAFF (параметры release) на сохранённых детекциях FastSAM с GT-позами, исключает детекции ближе 0.6 м к пешеходам и другим роботам, записывает, какой трек обновила каждая детекция, и признаки маски |
| 2 | `analyze.py DETECTIONS_JSONL OBJECTS_TXT OUT_JSON` | любой Python с NumPy | Строит пары наблюдений внутри треков, считает квантили расхождения центров по группам признаков, переносит границу с трёх роботов на четвёртый, проверяет треки по GT-коробкам |

`WORKSPACE` — внешняя рабочая область со структурой исходного проекта: `data/tcaff_mot_data`, `vendor/tcaff`, `.venv` ([подготовка](../../docs/reproduction.md)). Промежуточный `detections.jsonl` содержит производные данные авторской записи и в репозиторий не входит.
