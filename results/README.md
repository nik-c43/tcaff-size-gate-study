# Сохранённые собственные результаты

Основные числа: [evidence.csv](evidence.csv) / [evidence.json](evidence.json), каноническая интерпретация — [report.md](../report.md). Таблица явно указывает область, определение метрики, конфигурацию, источник и команду; лёгкое повторное агрегирование не выдаётся за повтор алгоритма.

| Каталог | Содержимое |
|---|---|
| `baseline/` | Исходный release audit и lossless-сжатые вычисленные ошибки 4044 обновлений |
| `size_gate/` | Selection, development, холодный старт, полная история, подсчёт меток и компактные вычисленные метрики 420 прогонов |
| `occlusion/` | 80 случаев собственной идеальной модели и три синтетические маски; не авторские RGB-D |
| `diagnostics/` | Компактные сводки выполненной диагностики и прежние проверки целостности |
| `history/` | Прежние отрицательные B0/B3 и MNO 4→16; другие протоколы, не текущий baseline |
| `figures/publication/` | Переоформленные научные PNG/SVG и plot provenance |

В compact run metrics поля каждого кадра: `[step,time,accepted,[translation_m,yaw_deg] или null,correct,runtime_s,gt_available]`. Сохранены исходный путь/хэш и параметры каждого прогона. Карты, исходные GT-позы, FastSAM наблюдения и полные предложения сюда не копируются. Повтор вычисления ошибок от поз требует внешнего snapshot.

Копии итоговых JSON заменяют локальные абсолютные пути только в строковой метаинформации. Численные поля сохранены. [Inventory](../docs/source_inventory.json), [проверки](../docs/validation.md), [команды](../docs/reproduction.md).
